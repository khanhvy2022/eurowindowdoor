# AI Instruction Rules (.ai-rules.md)

This file contains coding guidelines, standards, and behavioral constraints for all AI coding agents working in this repository.

## 1. Core Directives
*   **Prioritize Existing Architecture:** Do not rewrite or redesign existing systems unless explicitly requested. Align with current design patterns, state management, and component architecture.
*   **Do Not Break Working Code:** Ensure backward compatibility. Check imports, exports, type definitions, and dependencies carefully.
*   **Build Before Commit:** Always run the build process (`npm run build` or equivalent) to verify that there are no compilation, bundler, or build-time errors.
*   **Strict Type Checking:** Perform self-checks for TypeScript errors (`npm run tsc` or similar) before claiming a task is done.
*   **Strict Linting Rules:** Check and fix ESLint errors (`npm run lint` or `npx eslint . --fix`) to maintain codebase cleanliness.
*   **Clean Repository State:** Do not leave unused files, backup files, or console logs. Keep file and folder names clean and semantic.
*   **Explain Major Changes:** When submitting substantial refactors or changes, provide a concise explanation detailing the rationale, key modifications, and verification steps.

---

## 2. Component & UI Guidelines (React & Next.js)
*   **Component Modularity:** Write small, single-purpose components. Keep logical state close to where it is used.
*   **TypeScript Correctness:** Avoid using `any`. Define strict types for props, state, API requests, and event handlers.
*   **Styling Consistency:** Use existing styling frameworks (e.g., Tailwind CSS, CSS Modules) and maintain standard color tokens and layouts.
*   **SEO & Semantic HTML:** Ensure proper SEO tags, descriptive titles, meta descriptions, and semantic HTML5 tags (e.g., `<main>`, `<section>`, `<header>`).

---

## 3. Geometric & Spatial Guidelines (CAD, BIM, 3D)
*   **Geometric Accuracy:** When writing math and geometry calculations (scaling, translations, floorplan parsing), ensure maximum numerical precision.
*   **Coordinate Standards:** Maintain consistent reference systems for floorplans, GLB models, and Three.js scenes. Avoid arbitrary offsets.
*   **Asset Performance:** Optimize mesh structures, geometries, and materials in Three.js/GLB to prevent memory leaks and maintain 60 FPS rendering.
*   **IFC / DWG Parsing:** Maintain data fidelity when translating architectural PDF/DWG layout data to JSON/3D structures.
